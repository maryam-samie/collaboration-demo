# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## Project structure
- `app.txt`: Contains the project description.
- `.gitignore`: Lists temporary files that Git should ignore.
- `.github/workflows/ci.yml`: Defines the continuous integration workflow.

## How to contribute
1. Open an issue.
2. Create a branch for the issue.
3. Make your changes and commit them.
4. Open a pull request.
5. Address review feedback.
6. Check the pull request and CI results before merging.
